# 領収書の出し忘れチェック（1画面デモ）

## 何ができるか
- カード・通帳の明細と手元の領収書の一覧を貼ると、「明細はあるのに領収書がない」「領収書はあるのに明細にない」ものを洗い出す。
- 「金額が同じで日付が近い（既定±3日）」ものを同じ取引と見なして1対1で照合する。
- 月ごとの件数・領収書なしの件数・合計と、結果のCSVが出る。

## 使い方
1. `index.html` をブラウザで開く（サンプルは架空のデータ。「サンプルを消す」で空になる）。
2. 左に明細、右に領収書を貼る。1行1件、「日付・メモ・金額」の順（Excelのコピー／カンマ区切りどちらも可）。
3. 「照合する」を押す。読めない行は赤く表示される。

## 限界
- 照合は目安。同額・近日付が複数あると、近い順に割り当てるだけで、取り違えはありうる。最終確認は目視。
- 税務判断（経費にできるか、科目）はしない。年なしの日付、小数・0円・マイナスの金額は読まない。
- 入力は画面内で処理し、保存も送信もしない（再読み込みで消える）。依存なしの単一HTML。

## 検証
- `node verify.mjs`：読み取り・照合の固定ケース＋乱数200回（真の対応との一致）。
- `node ui-check.cjs <playwrightのnode_modules>`：headless chromiumで画面操作・CSV・390px幅・外部通信0を確認。
